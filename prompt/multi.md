## 流れ
- 現在のノードから候補のエッジ N 個を並列実行対象にして、各スレッドで以下を行う
    - エッジをロックする
    - エッジを実行し、シミュレーションを行う
        - ショットのルール違反を検知したら
            - z = 0 とする
            - エッジを訪問禁止にする
            - 報酬の逆伝播を行う(特殊処理)
    - 局面評価を Pending に登録して待ち状態に入る
    - 局面評価を受け取ったら、
        - 次のエッジを選択する
        - エンド終了なら
            - エッジをアンロック
            - 報酬の逆伝播を行う

### 局面評価
- Pending に登録された M 個の局面が登録されたらシングルスレッドで行う

### 報酬の逆伝播
- 親ノードの W, N をロックする
    - W <- 子ノードの報酬
    - N <- +1（特殊処理なら +0）
- 親ノードの W, N をアンロックする
