# 前提
このシミュレータのsimulateを利用して、UCTを実装したいです。
カーリングAI実現のために、ショットの選択フローは既に以下のように実装されています。

- 試合状況を受け取る
    - 盤面情報
    - 得点情報
    - 次にショットを打つチーム
- ニューラルネットワークに試合情報を入力し、2048個の (vx, vy, spin) の候補手の打つべき確率分布を出力する
- 決定したショット(vs, vy, spin)を公式のシミュレートサーバに送信する

# 目的
ニューラルネットワークの出力で、最も確率分布の高いショット (vx, vy, spin) をそのまま公式のシミュレートサーバに送信して試合を進めるよりも、ニューラルネットワークの出力を基にUCTでエンド終了まで探索を行った方が、より優れたショット (vx, vy, spin) を選択できると考えています。

# 目標
UCT中のシミュレーションに simulate を使ったUCTをショットの選択フローに追加して、以下のようにしたいです。
- 試合状況を受け取る
    - 盤面情報
    - 得点情報
    - 次にショットを打つチーム
- ニューラルネットワークに試合情報を入力し、2048個の (vx, vy, spin) の候補手の打つべき確率分布を出力する
- 「UCTを行いより優れたショットを選択する」
- 決定したショット(vs, vy, spin)を公式のシミュレートサーバに送信する
